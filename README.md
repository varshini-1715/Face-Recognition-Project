# Face Recognition Project

A deep learning-based face recognition system using InsightFace.

## Features

- Face detection
- Face recognition
- Face embedding generation
- Cosine similarity-based comparison
- Unknown face detection
- Test image visualization

## Technologies Used

- Python
- InsightFace
- OpenCV
- NumPy
- Scikit-learn
- Matplotlib
- Google Drive / gdown

## Dataset

The dataset is downloaded from Google Drive when the program is executed.

## Project Type

Deep Learning / Computer Vision / Face Recognition
